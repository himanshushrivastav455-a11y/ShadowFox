# ShadowFox Advanced Web Scraper

## Features

-   Beautiful Soup scraper
-   Multi-page scraping
-   CSV export
-   JSON export
-   SQLite database
-   Logging
-   Timestamp for each record
-   User chooses pages

## Run

``` bash
pip install -r requirements.txt
python scraper.py
```

Target website: https://books.toscrape.com (practice site for scraping)
